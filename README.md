# 🐱🔫 Мяу-Ган

Idle-шутер про котика-стрелка в духе *Idle Cat: Gunner Shooter RPG*.
Котик сам отстреливается рыбками от мышей, крыс и псов, а ты решаешь, во что вложить золото.

## Как запустить

Нужен любой статический сервер (ES-модули не работают через `file://`):

```bash
npm start            # python3 -m http.server 8080
# открыть http://localhost:8080
```

## Что уже есть

- Автострельба с самонаводящимися пулями-рыбками, криты, всплывающий урон, монетки, тряска экрана
- 7 улучшений (урон, скорострельность, здоровье, регенерация, шанс и сила крита, жадность), покупка ×1 / ×10 / МАКС
- Этапы по 10 врагов, босс каждые 5 этапов с таймером 30 с, откат при провале и кнопка «В бой с боссом»
- 3 навыка (Рыбный залп, Кошачья ярость, Мурчание) + авто-применение
- 4 биома с процедурной графикой: Сад, Город, Крыши, Космос
- Перерождение за рыбьи косточки (+10% урона и золота за каждую)
- Оффлайн-доход до 8 часов, автосохранение в браузере

## Структура

| Путь | Роль |
|---|---|
| `src/config.js` | все балансные константы |
| `src/formulas.js` | чистые формулы экономики (тестируются) |
| `src/state.js` | состояние игрока, покупки, перерождение, сохранения, оффлайн |
| `src/battle.js` | боевая симуляция без DOM (тестируется в Node) |
| `src/render.js` | процедурная отрисовка на Canvas |
| `src/main.js` | игровой цикл и интерфейс |
| `docs/GDD.md` | дизайн-документ и бэклог |
| `tools/simulate.mjs` | симуляция прогрессии для настройки баланса |

## Разработка

```bash
npm test             # юнит-тесты (node:test, без зависимостей)
npm run simulate     # за сколько минут достигаются этапы
```
