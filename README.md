# 🐱🔫 Мяу-Ган

Idle-шутер про котика-стрелка в духе *Idle Cat: Gunner Shooter RPG*.
Отряд котиков сам идёт вперёд и отстреливается, а ты собираешь арсенал: покупаешь пушки, сливаешь одинаковые и раздаёшь лучшие.

## Как запустить

Нужен любой статический сервер (ES-модули не работают через `file://`):

```bash
npm start            # python3 -m http.server 8080
# открыть http://localhost:8080
```

## Что уже есть

- Отряд до 3 котиков (Рыжик, Снежок, Уголёк) с бонусами для всего отряда
- Слияние оружия: 30 уровней, 6 семейств (пистолет, автомат, дробовик, винтовка, снайперка, миниган) со своей механикой стрельбы
- Отряд идёт вперёд: деревья, камни и ящики с оружием преграждают путь, золотая мышь пытается убежать
- 8 улучшений (включая Кузню, повышающую уровень покупаемых пушек), покупка ×1 / ×10 / МАКС
- Босс каждые 5 этапов с таймером 30 с, откат при провале и кнопка «В бой с боссом»
- Кейсы с оружием: рулетка, суперприз 1%, гарантия на каждый 10-й кейс, золотой кейс за ключи с боссов
- Ускорение игры ×2 / ×3 (×5 после первого перерождения)
- 3 навыка + авто-применение
- 6 локаций с параллаксом: Лес, Пустыня, Снежные горы, Город, Крыши, Космос
- Перерождение за рыбьи косточки, оффлайн-доход до 8 часов, автосохранение
- Синтезированные звуки (WebAudio, без файлов)

## Структура

| Путь | Роль |
|---|---|
| `src/config.js` | все балансные константы |
| `src/formulas.js` | чистые формулы экономики (тестируются) |
| `src/state.js` | состояние игрока, арсенал и слияние, покупки, перерождение, сохранения |
| `src/battle.js` | боевая симуляция без DOM (тестируется в Node) |
| `src/render.js` | процедурная отрисовка на Canvas |
| `src/audio.js` | синтезированные звуки |
| `src/main.js` | игровой цикл и интерфейс |
| `docs/GDD.md` | дизайн-документ, разбор оригинала и идеи |
| `tools/simulate.mjs` | симуляция прогрессии для настройки баланса |

## Разработка

```bash
npm test             # юнит-тесты (node:test, без зависимостей)
npm run simulate     # за сколько минут достигаются этапы
```
